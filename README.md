## 📖 About

SkyPulse is a modern weather forecasting web application built using **HTML, CSS, and Vanilla JavaScript**.

The application allows users to search for any city worldwide or use their current location to view accurate weather information, hourly forecasts, and 5-day predictions. It also provides detailed weather statistics like humidity, UV Index, wind speed, pressure, visibility, sunrise & sunset timings, and much more.
